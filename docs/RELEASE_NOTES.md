Linux desktop build of DeepSeek Harness __VERSION__.

## Install

- **AppImage:** download, `chmod +x`, run.
- **Debian/Ubuntu:** `sudo apt install ./deepseek-harness-__VERSION__-linux-amd64-unsigned.deb`
- **Fedora/RHEL:** `sudo dnf install ./deepseek-harness-__VERSION__-linux-x86_64-unsigned.rpm`
- **One-line installer:** `curl -fsSL https://github.com/butterpurse-dot/deepseek-harness-linux/releases/latest/download/install-linux.sh | bash`

The x64 and arm64 AppImages auto-update. arm64 also has a separate release for manual downloads:
https://github.com/butterpurse-dot/deepseek-harness-linux/releases/tag/v__VERSION__-arm64

`SHA256SUMS.txt` is attached.
