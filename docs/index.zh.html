DeepSeek Harness，
为 Linux 打包。

官方 Electron 桌面应用，内置 Node、pnpm 和 Python 运行时——提供 AppImage、.deb、.rpm 和 .tar.gz。自动更新、校验和验证、一条命令安装。

下载 查看源码
curl -fsSL https://github.com/butterpurse-dot/deepseek-harness-linux/releases/latest/download/install-linux.sh | bash

安装到 ~/.local。支持 x64 和 arm64。社区构建，非 DeepSeek 官方项目。

真正的桌面应用，不是浏览器套壳。所有运行时都随包提供，无需管理系统 Node。

安装

一条命令会自动选择架构、校验校验和，并添加桌面入口。

一条命令

curl -fsSL https://github.com/butterpurse-dot/deepseek-harness-linux/releases/latest/download/install-linux.sh | bash

需要 curl 和 python3。安装到 ~/.local；可传 --prefix /usr/local 更改位置。

手动安装

# AppImage
chmod +x deepseek-harness-*.AppImage
./deepseek-harness-*.AppImage

# Debian / Ubuntu
sudo apt install ./deepseek-harness-*.deb

# Fedora / RHEL
sudo dnf install ./deepseek-harness-*.rpm

# Portable
tar -xzf deepseek-harness-*.tar.gz
./deepseek-harness-*/deepseek-harness

部分发行版运行 AppImage 需要 FUSE 2：sudo apt install libfuse2 或 sudo dnf install fuse2。

更新

x64 和 arm64 AppImage 会在启动时及每六小时检查 GitHub Releases。应用会先询问是否下载，选择 Install and Restart 后安装。

从终端更新

dsh-update --check   # is a newer release available?
dsh-update           # download, verify and install it
dsh-update --force   # reinstall the current release

arm64 AppImage 通过 arm64 feed 自动更新。同时也会发布单独的 v<version>-arm64 release 供手动下载。

社区构建

这是一个下游打包项目，不是 DeepSeek 官方产品。上游桌面端面向 macOS 和 Windows；本仓库补充 Linux 打包、CI 和安装器。

维护

尽力而为，没有 SLA，也没有常驻维护者。上游发布由自动化同步；Issue 和 Pull Request 由社区在有时间时处理。如果同步工作流被阻塞，会打开 upstream-sync issue，任何人都可以修复。
